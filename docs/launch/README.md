# Launch kit

Go-to-market drafts for groundtruth. **These are drafts for a human to review and post** — nothing here is auto-published.

| File | What | Where it goes |
|---|---|---|
| [CHECKLIST.md](CHECKLIST.md) | The ordered launch sequence (do this first) | — |
| [show-hn.md](show-hn.md) | Show HN title + maker's first comment | news.ycombinator.com |
| [x-thread.md](x-thread.md) | Launch thread | X / Twitter |
| [reddit-post.md](reddit-post.md) | Post + subreddit notes | r/ClaudeAI, r/SideProject |
| [product-hunt.md](product-hunt.md) | Tagline, description, maker comment | Product Hunt |
| [devto-article.md](devto-article.md) | Full launch article | dev.to / Hashnode |
| [awesome-claude-code-submission.md](awesome-claude-code-submission.md) | Entry + submission steps | awesome-claude-code |
| [good-first-issues.md](good-first-issues.md) | Issue specs to open | GitHub Issues |

Every claim in these drafts is fact-checked against the codebase and the cited
research ([Gong et al., MSR'26 — arXiv:2601.04886](https://arxiv.org/abs/2601.04886)).
Keep it that way: this is a tool about not making claims you can't back up.
